# Experiment design

- Derive a falsifiable prediction before choosing explore/optimize/repeat. Explain
  which variable or contrast distinguishes the hypothesis from competitors.
- State fixed controls, comparator, independent repeat strategy and objective
  support/refutation/inconclusive criteria before seeing the result.
- Propose exactly one next physical condition. Label later comparisons/repeats as
  planned; do not claim that one condition completes an unperformed comparison.
- Respect frozen range, stock, additive, material and undiluted-stock constraints.
  Do not depend on Python silently repairing the design after QA.
- If no justified feasible test exists, return experiment=null with an explanation.
  Report limitations and material QA revisions in the readable report.
