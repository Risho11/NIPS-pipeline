# Analysis guide

- State the observed trajectory and modulus/changepoint tradeoffs with condition
  and source references. Inspect controls, fit exclusions, quality reports and
  material/bath changes. Separate graph observations from causal explanations.
- Distinguish specimen variation, independent `_runN` syntheses and processing
  variants. Assess whether prior predictions were supported, refuted or still
  inconclusive. Do not judge a hypothesis only by performance improvement.
- Identify confounding, missing evidence and plausible alternative explanations.
  Describe which observations could discriminate them without choosing conditions.
- Report figure paths, unavailable visual inspection, limitations and material QA
  revisions. Never fabricate measurements, analysis code execution or a QA pass.
