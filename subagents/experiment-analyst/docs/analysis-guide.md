# Answering an experimental analysis question

This guide supports the explicitly invoked [analyst role](../AGENTS.md). Use the
shared [data contract](../../../docs/mas/data-contract.md) for actual fields,
units, processing and source identity, and
[analysis methods](../../../docs/mas/analysis-methods.md) for common calculations.
The [workflow](../../../docs/mas/workflow.md) explains main's decisions and
scientific review. These methods describe target/pilot work; actual sandbox and
output requirements still apply. Your assignment is a bounded split issue chosen
by main under the workflow, with duties, evidence, review coverage and a concrete
rejoin condition. The default integrated author can perform these methods itself;
no separate analyst is mandatory every round. Unified `hypothesis-qa` reviews all
inquiry contributions; additional review is only the workflow's exceptional fresh
same-role issue review. Legacy analysis QA is not part of this target routing.

## Turn the inquiry into an evidence comparison

In observation turns, recover the preserved theory-informed predictions and relevant
bank origins before inspecting authorized outcomes. Compare agreements and surprises;
observations may challenge prior accounts or motivate new ones. Keep data-generated
ideas exploratory and do not count the same data as independent confirmation.
Bootstrap theory does not require this analysis first, and a historical reveal
is not a new prospective experiment. Reuse relevant bank records across turns.

Identify which process questions the authorized evidence could usefully address,
not only how to summarize the latest high point. Compare relevant available
contrasts and control gaps across the applicable data/history, guided by the
objective rather than a fixed variable checklist. Explain which comparison could
change the next decision and why it deserves attention. If judging a prior
prediction, establish actual execution and its comparator first; otherwise label
the interpretation retrospective rather than inventing a tested prediction.

Locate numeric outcomes in the original table and inspect its header. Trace
promoted values to the appropriate aggregate version when quality or exclusion
could matter. Use specimen/curve evidence for within-synthesis or fitting claims,
not aggregate SD as a substitute. Treat warm-start history as another source to
assess, not automatically another independent experiment. If source identities
collide, disclose the collision and ask main for provenance before counting both.

Choose comparators that answer the question. Identify which variables are matched,
which changed and which are unknown. An exact condition-name match is a clue,
not proof of physical identity or identical materials. If matched evidence is
absent, describe the joint change and competing explanations rather than force a
single-factor effect. Do not backfill historical material settings from current
operator context.

## Select a calculation or artifact for a reason

For a process explanation, distinguish the observation from the reason for its
proposed intermediate and direction. Provide relevant source contrasts, process
sequence and contrary evidence for updater/QA, rather than restating higher E
as a “stiffer network.” A preparation setpoint does not establish a retained
state after later treatment. Ask what available observation separates credible
accounts; if the same property outcomes fit both, say which narrower process-
effect question can still be tested and what mechanisms remain unresolved.

Optimization targets do not exhaust explanatory evidence. Select other already-
available measured responses or provenance when a credible prediction makes them
informative, rather than defaulting to targets alone. Check actual definitions,
contributing samples and fitting context: descriptors from shared curves/processing
are not independent microstructure evidence. Do not analyze every feature, refit
or add assays by default.

Follow [knowledge.md](../../../docs/mas/knowledge.md) for claim meanings and
variable coverage without importing worked causal answers. Modulus is normalized: total mass/thickness alone cannot establish
a material-response change. Coverage photos do not image cross-sections. Discover
and inspect consequential authorized originals before declaring them unavailable.
Return source precision, inference limits, useful alternatives and question
priorities for the round's knowledge update; main alone publishes shared claims.

If the question concerns a measured difference, calculate the contrast at source
precision and report units, direction, comparator and inclusion choices. A
relative contrast needs a meaningful nonzero denominator. If the question is
repeatability, establish which observations are independent syntheses before
using their variation; show the outcomes when independent coverage is sparse.
Check counts by property where available, not just one count for a whole row.

If the question concerns quality, compare pre/post-discard interpretations and
contributing specimens. Inspect fit breakdowns and original curves where they
could change the conclusion. A missing successful fit means unavailable evidence
for that property, not zero physical performance. If a measurement/fit concern
cannot be resolved from supplied sources, distinguish that from evidence against
the material itself and request the necessary source through main.

Choose the representation that makes the unresolved comparison visible. A
condition table can reveal simultaneous changes or unknown controls. A stratified
scatter can reveal that an apparent trend follows composition groups. Specimen
points plus a source fit overlay can clarify a suspect estimate. Stratification
alone does not remove confounding when there is no matched contrast. Do not make
all of these artifacts by default.

For an authorized script/figure, record its input paths, exact row selectors,
properties, units, processing variants, exclusions and transformations. Inspect
the actual rendered output where possible; verify that missing values were not
plotted as zero, axis/group labels mean what the text claims, and specimen SD was
not relabeled as synthesis uncertainty. Record command outcomes truthfully. If
visual inspection is unavailable, state which conclusions rely only on the table
or computation. Existing deterministic plots are not a substitute for checking
their underlying fields.

## Resolve the bounded issue and hand it back

Use both physical/chemical reasoning and data science. Determine whether competing
defensible preprocessing/strata/model choices change the action; check relevant
nonlinear, interaction, regime and dispersion behavior without a fixed method suite.
For method construction/repair, bind the missing/invalid analysis/model/evaluation
method, blocked action, concrete task and validity check. Routine CSV reading,
arithmetic or a figure with an applicable method alone is not a split trigger;
a method gap does not require an authored error. Correlated inputs and response
interaction differ. When predictions drive a
choice, assess held-out sufficiency, independence/grouping and sensitivity using
the shared analysis methods. Do not treat in-sample model explanations as cause.

If QA identifies a selection or processing error, preserve the initial result and
explanation, repair affected comparisons and sweep artifacts sharing that cause.
Inspect available originals before proposing new acquisition; missing per-specimen
fields cannot be reconstructed by renaming columns. State unresolved evidence
rather than inventing a method validation or another independent sample.

Return exact sources, alternatives checked, method/artifact locations and the
consequence for the next variable/region/action. Unified inquiry QA reviews both
authors; any additional review follows the bounded same-role issue rule. Main rejoins only after
the issue has a checked bounded resolution and independent affected review, while
persistent constraints remain visible. Unresolved action-changing choices keep
the issue open or require evidence/hold.

## Prediction agreement is different from improvement

Evaluate the preserved observable prediction and comparator/criteria. Lower
objective performance is not automatically a failed prediction.
Check execution, quality and criteria first; then report agreement, disagreement
or inconclusive evidence for the predicted observations. Formal hypothesis status
and selection remain with hypothesis maintenance/QA and main. Shared curve-fit
origins and alternative explanations may limit what agreement implies about a
mechanism.

When criteria were never stated, label a retrospective comparison; do not invent
a threshold after seeing the outcome. When the required outcome is missing,
report the relevant part as unassessed rather than borrow a historical value.

## Return a usable bounded answer

Separate what was observed, what interpretations remain plausible and what would
change the conclusion. Link original sources and artifact locations with enough
calculation detail for independent checking; no full-report JSON copy is needed
by the target method. Explain important revisions and which downstream claims
may be affected.

Stop adding analysis when no feasible check of available evidence could change
main's decision. Return the concrete missing evidence instead of generating more
plots to imply certainty. A limited but correct conclusion can be sufficient for
main to request a discriminating design or hold. Unresolved consequential errors
need repair and independent review; honest scientific uncertainty stays visible.

## Runtime handoff

The [runtime runbook](../../../docs/mas/python-runtime.md) owns current operational
receipt, workspace, cache and recovery semantics. Use `MAS_SOURCE_ROOT` for
source paths and only assigned attempt paths for findings/artifacts. Preserve
prior reviewed/failed versions, use the actual committed knowledge in design, and
return exact small operational values/paths when requested by Main. This does not
create a scientific stage order or give authors/reviewers publication/device rights.
