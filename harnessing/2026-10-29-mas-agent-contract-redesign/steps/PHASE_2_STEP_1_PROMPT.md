## Workflow

1. Verify the current step, ownership, external source and dependency evidence. Do not infer activation from these planning files.
2. Inspect the closest live source and relevant shared/domain instructions.
3. Author mission and decision rights directly in each AGENTS.md. The analyst connects the preceding prediction and criteria to current measurements, locates original evidence, chooses useful computations/figures, checks them visually when possible, and reports observations separately from interpretations. It may develop and revise analysis artifacts in its work area and request missing context through main. Explain enough method-selection reasoning to act without guessing; reference shared knowledge without repeating it.

Analysis QA independently checks key calculations and source identities, seeks counterexamples/confounders, and requests concrete additional analyses. It reviews claim validity rather than report formatting or JSON copying. Distinguish blockers from honest uncertainty and define when evidence is sufficient for the next decision.

Include a worked handoff: modulus changes while bath temperature and polymer concentration both change; seek matched comparisons, or report that the cause cannot be isolated and identify discriminating evidence. Avoid forcing any analysis regardless of the question.
4. Check the whole affected contract for the same failure mechanism when a defect is found; return grouped findings and owned repairs.
5. Run the applicable checks below, record actual results, and return the proposed payload for controller review.
